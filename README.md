# MotoFlow — prototype

AI dự báo ùn tắc ngắn hạn và điều phối đèn tín hiệu thích ứng cho giao thông hỗn hợp xe máy.
Địa bàn: TP. Hồ Chí Minh, trục Võ Văn Kiệt.

- `index.html` — prototype (mobile + bảng điều hành)
- `?screen=home|map|node|plans|alerts|safety|assistant` — mở thẳng một màn hình
- `?chrome=0` — ẩn khung thiết bị (dùng để chụp ảnh)
- `?mode=ops` — bảng điều hành desktop

Dữ liệu trong toàn bộ prototype là **mô phỏng có kiểm soát**, không phải số đo thực địa.
Hệ thống là công cụ hỗ trợ ra quyết định, không gửi lệnh trực tiếp xuống đèn thật.
